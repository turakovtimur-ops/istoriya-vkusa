# История Вкуса — Контекст проекта

## О проекте
Ресторанный холдинг в Геленджике: Кинза, Нино, Астория, Ла Коста Берег + партнёрские отели (Бригантина, Янтарь, Природа).
Заказчик: Тимур Тураков. Домен: istoriya-vkusa.ru.

## Стек
- React + Vite + TypeScript + Tailwind CSS
- Деплой: Vercel (временно), планируется переезд на SpaceWeb
- Аналитика: Яндекс Метрика (id: 112073069), отложенный старт через 2.5с после load
- Карта: Яндекс.Карты 2.1 (ленивая загрузка по IntersectionObserver)
- Админка: ленивый chunk через React.lazy

## Ключевые архитектурные решения
1. **SPA с client-side роутингом** через window.history (не React Router)
2. **Орбита на первом экране** — sunPulse анимируется через @keyframes на box-shadow (некомпозитно, осознанное решение для эффекта)
3. **Ленивая карта** — ymaps подключается только когда блок в viewport
4. **Метрика отложена** на 2500 мс после load — ради TBT 30 мс вместо 7540 мс
5. **Code-splitting**: Admin и EditMode в ленивые chunks

## Производительность (финал, октябрь 2026)
- Мобила: **75** 🟠 (TBT 30 мс, LCP 4.3с, FCP 3.2с, CLS 0)
- Десктоп: **96** 🟢 (TBT 40 мс, LCP 0.9с, FCP 0.3с, CLS 0.03)
- a11y: 89 (контраст бейджей cuisine — осознанно не тронут ради дизайна)
- SEO: 100
- Агентный: 2/4 (экспериментальная категория Google, не ранжирующая)

## Что сделано в перф-полировке
- Все картинки → WebP (сжато ~1.9 МБ)
- Логотип: 93 KiB PNG → 8.2 KiB WebP + width/height
- Code-split Admin/EditMode: главный бандл 311→285 KiB
- Self-host картинок (убраны внешние зависимости, кроме карт и метрики)
- Композитные ховеры (transition только на transform/opacity/bg/border)
- vercel.json с rewrites для llms.txt и ai-catalog.json
- <main> landmark

## Агентные файлы
- `/llms.txt` — markdown с H1 и ссылками (для LLM)
- `/ai-catalog.json` — манифест ARD
- curl показывает 200 с правильным контентом, PSI иногда фолбечит на HTML — это nginx, не файлы

## Что НЕ делали сознательно
- Self-host Google Fonts (Playfair Display + Inter): выигрыш +3–5 баллов мобиле ценой усложнения сборки. Оставили внешний CDN ради простоты поддержки.
- Контраст бейджей cuisine (белый на светлом акценте): ~1.9:1. Поднятие до нормы убьёт визуальный дизайн. Реальных скринридеров у ресторана нет.
- Агентный просмотр 4/4: категория экспериментальная, не влияет на поиск.

## Известные хвосты (не трогаем)
- `ymaps-2-1-79-copyright` ссылка без текста — код Яндекса, не наш
- sunPulse box-shadow — некомпозитно, но визуально важно
- 404 manager.jpg был почищен, но в старых PSI-отчётах может ещё мелькать
